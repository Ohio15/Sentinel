Installation Successful!

The Sentinel RMM Agent has been installed and the services are now running.

Next Steps

Important: If this is a fresh installation, you need to configure the agent with your server details.

Edit the configuration file:

sudo nano /etc/sentinel/config.json

Then restart the services:

sudo launchctl unload /Library/LaunchDaemons/com.sentinel.agent.plist
sudo launchctl load /Library/LaunchDaemons/com.sentinel.agent.plist

Useful Commands

Check service status:

launchctl list | grep sentinel

View agent logs:

tail -f /var/log/sentinel/agent.log

To uninstall, run:

sudo /usr/local/bin/sentinel-uninstall.sh

Click Close to exit the installer.
