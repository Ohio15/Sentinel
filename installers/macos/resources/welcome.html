Welcome to Sentinel RMM Agent

This installer will set up the Sentinel Remote Monitoring and Management (RMM) agent on your Mac.

What will be installed:

  • Sentinel Agent - The main monitoring and management service
  • Sentinel Watchdog - Ensures the agent stays running

Installation locations:

  • Binaries: /usr/local/bin/
  • Configuration: /etc/sentinel/
  • Logs: /var/log/sentinel/
Note: Administrator privileges are required to install system services.
